# 👤 Random User Generator 

A simple and interactive Random User Generator built using HTML, CSS And JavaScripr.

This project uses the Random User Api to generate fictional user profiles for learning And demostration purposes.

## 🚀 Live Demo

[View Live Demo]:- https://yamunakumari890.github.io/Random-User-Generator/

## ✨ Features

- 👤 Generate random user profiles
- 📸 Display user profile picture
- 📝 Display user's name
- 📧 Display user's email
- 🌍 Display user's country
- 🔄 Generate a new user with one click
- 📱 Responsive and clean user interface

## 🛠️ Technologies Used

-HTML5
-CSS3
-JavaScript
-Fetch API
-Async/Await
-Random User API

## 🔌 API Used

This Project uses the random User API to generate fictional user data.

API EndPoint: 'https://randomuser.me/api/'(Project use)

API EndPoint: 'https://randomuser.me/api/?nat=in'(only Indian's users)
